🚀 CÓMO USAR

MÉTODO 1: Con Visual Studio Code (Recomendado)
───────────────────────────────────────────────
1. Descarga TODOS estos archivos:
   - index.html
   - styles.css
   - script.js
   - musica.mp3
   - GyJ.jpg
   - GYJ2.jpg

2. Crea una carpeta llamada "flores-giuli" en tu computadora

3. Coloca todos los archivos en esa carpeta

4. Abre Visual Studio Code

5. Arrastra la carpeta al editor (File → Open Folder)

6. Descarga e instala "Live Server" (extensión de VS Code)

7. Haz clic derecho en index.html → "Open with Live Server"

8. ¡La página se abrirá en tu navegador automáticamente! 🎉

MÉTODO 2: Directo en el navegador
──────────────────────────────────
1. Coloca los 6 archivos en la misma carpeta

2. Haz doble clic en index.html

3. ¡Se abrirá en tu navegador! 🌻

=================================================================
💡 PERSONALIZACIONES OPCIONALES
=================================================================

Si quieres cambiar colores en el ramo:

1. Abre "styles.css" con el editor de código

2. Busca ".ramo-flores-principal" (alrededor de la línea 730)

3. Cambia estos valores:
   - #FFD700 = color de pétalos (amarillo)
   - #FFA500 = color alterno de pétalos (naranja)
   - #2d5016 = color de tallos (verde oscuro)
   - #3d7a2e = color de hojas (verde)

4. Guarda el archivo

5. Recarga la página en el navegador (F5)
